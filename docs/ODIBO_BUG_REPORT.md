# ODIBO PDF — voluntary bug report / Добровольный отчёт

Reporting is optional. ODIBO does not automatically upload this form, PDFs or logs.
GitHub Issues is not an available reporting channel for this repository at present.
Open the candidate under [Pull requests](https://github.com/imranOdiboev/pdfcraft/pulls)
and, if its discussion is open, paste the report in that PR's conversation. This is
a public GitHub discussion: review everything before submitting. If comments are
unavailable, keep the report locally and ask the owner for an approved channel;
no email address or private-upload service is configured here.

Сообщение добровольное. Найдите PR проверяемой сборки и оставьте текст в его
обсуждении, если оно доступно. Обсуждение публичное; GitHub-имя автора будет видно.
Если отправить нельзя, сохраните текст у себя и согласуйте канал с владельцем.
Программа ничего автоматически не загружает.

**Do not attach personal or work PDFs, passwords, keys, certificates, digital-ID
files, control tokens or unredacted logs.** Reproduce on a synthetic document where
possible. An optional screenshot must exclude personal paths, usernames, recent
documents, account details and other private content. Check error messages too.
No attachment is required to report a failure.

**Не присылайте личные PDF, пароли, ключи, сертификаты и необработанные логи.**
Сначала попробуйте синтетический документ. Вложения необязательны; уберите из
скриншота и текста ошибки личные пути, недавние файлы и сведения об учётной записи.

```text
ODIBO version / версия:
Source commit and CI run / исходный коммит и запуск:
Setup or Portable; exact package name / пакет:
Windows version, x64; ordinary/admin account / Windows, права:
Language, theme, scale, window size / язык, тема, масштаб, окно:
Operation / операция: install, update, uninstall, open, combine, split, other:
Minimal steps with a synthetic document / шаги на учебном документе:
Expected / ожидалось:
Actual / получилось:
Reproduces how often / сколько раз повторяется:
Original and existing output unchanged? / исходник и прежний результат сохранены?:
Exact error, with private details removed / обезличенная ошибка:
Optional synthetic example or redacted screenshot / необязательное вложение:
```

A public report is not a confidential security channel. For a suspected exploitable
security issue, do not post exploit files, credentials or private data publicly; ask
the owner to establish an appropriate private reporting route. No response-time or
deletion guarantee for a public GitHub discussion is promised here.
