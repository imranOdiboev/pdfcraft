# ODIBO PDF interface screenshots

These images document the actual ODIBO PDF Rust/egui interface. They are captured
by the project's `crates/ui-egui/examples/shot.rs` using egui_kittest and wgpu on a
disposable **Linux GitHub Actions runner**. They are not native Windows captures,
HTML mockups, generative images, competitor screenshots or user feedback.

## Content and permissions

- The interface, layout and synthetic documents are produced from this project's
  source. The captures contain no personal PDFs, account information or private
  recent-file history.
- Capture runs set `PDFCRAFT_SYSTEM_FONTS=0`. Only the permitted embedded font
  resources and existing project icons are rendered. No installed proprietary
  system font is copied into a screenshot or document.
- Screenshot contributions use the repository's `MIT OR Apache-2.0` code licence,
  subject to the separate rights in the depicted assets. Existing fonts and icons
  retain their documented licences.
- ODIBO marks visible in screenshots remain under
  [LicenseRef-ODIBO-Brand](../../../assets/odibo/LICENSE-ODIBO-BRAND.txt).
  The brand terms permit sharing project screenshots to describe or review ODIBO
  PDF. They do not become MIT/Apache-2.0 graphics by appearing in a screenshot.
- Each published PNG must have an individual entry, exact source commit, capture
  run URL and SHA-256 in [ATTRIBUTION.toml](../../../ATTRIBUTION.toml).
  [ATTRIBUTION.md](../../../ATTRIBUTION.md) is generated by `cargo xtask assets --write`;
  it is not edited manually.

The README links to these permanent repository paths. GitHub Actions artifacts
remain verification evidence with limited retention, not image hosting for the
README. Synthetic pages illustrate the interface and do not establish fidelity
on arbitrary real documents or native Windows accessibility.

## Publication gate

Do not publish the gallery until the lead has downloaded and inspected the current
M3.7 captures, verified their source and hashes, added the individual attribution
entries, regenerated `ATTRIBUTION.md`, and obtained a passing `cargo xtask assets`.
Capture-specific run and commit evidence must be recorded in the entries before
the showcase PR is marked ready for review.
