## Подготовка

- Сохранить личную работу и закрыть ODIBO PDF. Не проверять сбой записи на реальных
  документах. Создать отдельную локальную тестовую папку NTFS с кириллицей в пути.
- Подготовить два синтетических PDF с понятными номерами страниц; один — шесть
  страниц. Сохранить отдельные неизменяемые копии или SHA-256 исходников.
- Проверить источник, коммит и хеши согласно [инструкции](ODIBO_WINDOWS_INSTALLATION.md).
  При блокировке Windows остановиться и записать предупреждение; защиту не отключать.

## Установка и приложение

| Проверка | Ожидаемое поведение | Результат |
|---|---|---|
| Чистая установка Windows 10 x64 | Отдельная фактическая проверка на Windows 10; предыдущий CI не считать её выполнением | Не проверено |
| Чистая установка Windows 11 x64 | Отдельная фактическая проверка на Windows 11 | Не проверено |
| Обычный пользователь | Setup в пользовательскую папку без запроса администратора | Не проверено |
| Отмена мастера до установки | Программа не установлена, исходные документы прежние | Не проверено |
| Завершение Setup | Правильные имя ODIBO PDF, версия, издатель IMR4N; запись в приложениях и ярлык «Пуск» | Не проверено |
| Первый запуск | Home и PDF Editor открываются; нет автоматического запуска MCP/обновления/облачного запроса для базовой работы | Не проверено |
| Открытие PDF из кириллического пути | Файл читается, порядок страниц ожидаемый; исходник не изменён | Не проверено |
| Combine | Второй PDF поставить первым, сохранить через «Сохранить как», открыть результат и проверить все страницы; исходники прежние | Не проверено |
| Split | Для шести страниц диапазоны 1–3 и 4–6, отдельная папка; обе части по три страницы, исходник прежний | Не проверено |
| Ошибка/отмена Split | Неверный диапазон и существующее имя результата отклоняются; отмена выбора папки не меняет документы | Не проверено |
| Аннотация и сохранение | Добавить тестовый комментарий с кириллицей, сохранить новую копию и открыть; видимая подпись не называется криптографической | Не проверено |
| Настройки и повторный запуск | Выбранные язык/тема/масштаб сохраняются, документ открывается вновь | Не проверено |
| RU/EN, темы и DPI | Обе темы, оба языка, 100/150/200%; читаемые подписи, доступные кнопки и клавиатурный фокус | Не проверено |
| Состав установки | Оба EXE, OCR-модели и их лицензии, LICENSE-MIT/APACHE, NOTICE, attribution, сторонние и брендовые условия на месте | Не проверено |
| Повторный запуск того же Setup | Понятный исход; нет дубликатов регистрации, потери документов/настроек | Не проверено |
| Обновление предыдущей сборки | Сохранить настройки, закрыть приложение, установить новый кандидат по инструкции; настройки и тестовые файлы прежние | Не проверено |
| Отмена при обновлении | Старое приложение и пользовательские данные остаются пригодны для работы | Не проверено |
| Удаление через Windows | Установленные файлы и ярлыки удалены; документы, настройки и восстановление сохранены | Не проверено |
| Установка после удаления | Приложение вновь запускается, сохранённые настройки читаются; документы прежние | Не проверено |

Для обновления запишите обе версии, SHA и запуски CI. Не выдавайте повторную установку
одного и того же пакета за проверку перехода между разными сборками. Если более раннего
проверяемого Setup нет, настоящий переход остаётся «не проверено»; CI-синтетический
предыдущий пакет следует называть именно синтетическим.

## Portable и сохранность

- Распаковать целый Portable ZIP отдельно, сохранить `portable.txt`; запустить EXE.
- Проверить, что настройки portable хранятся в его `ODIBOPDFData`; при предупреждении
  о недоступной записи не считать изоляцию пройденной. Windows имеет собственные кэши.
- Выбрать разные тему/язык в установленной и portable-копиях, закрыть и открыть
  каждую; настройки не должны неожиданно переноситься между ними.
- Выполнить открытие, объединение, разделение и Save As из portable. Сравнить исходники.
- Удалить установленную версию и снова запустить portable. Его файлы и настройки
  должны сохраниться. Не удалять папку portable, если нужны её документы/данные.
