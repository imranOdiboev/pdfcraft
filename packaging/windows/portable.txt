ODIBOPDF portable mode

While this file sits next to odibo-pdf.exe, ODIBO PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the ODIBOPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move ODIBOPDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\ODIBO PDF and
%LOCALAPPDATA%\ODIBO PDF) instead. If ODIBOPDFData can't be written (for example on a read-only
drive), ODIBO PDF says so and uses the per-user folders instead.
